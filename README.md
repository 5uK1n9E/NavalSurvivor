# 海上军舰 - Naval Survivor

吸血鬼幸存者风格的 2D 海上军舰生存游戏，Python + Pygame 实现。
仅用于个人学习娱乐使用
素材部分源自于网络，若有侵权请联系删除
大部分素材来自于ai生成

## 运行方式

### 方法一：Python 运行
```bash
cd `NavalSurvivor_v1.0
python naval_survivor.py
```

### 方法二：运行打包好的 exe
双击 `dist/NavalSurvivor.exe` 直接运行，无需安装 Python。

## 操作说明

- **WASD / 方向键**：移动军舰
- **按住空格**：冲刺（速度提升1.8倍，燃料消耗加倍）
- **鼠标瞄准**：弹幕向鼠标方向发射，自动射击
- **ESC**：暂停/返回菜单
- **游戏结束后**：点击"再来一局"或按回车重新开始

## 游戏模式

### 生存模式
- 完成 10 波敌人进攻即可胜利
- 敌人数量随波次递增
- 敌人类型随波次变化（侦察艇 → 巡洋舰 → 战列舰）

### 故事模式
- 分为 3 场战斗，每场战斗前播放对应幕的 CG 剧情
- **第一战**：刘公岛誓师 → 战斗 → 第二幕剧情
- **第二战**：黄海初阵 → 战斗 → 第三幕剧情
- **第三战**：威海困局 → 战斗 → 结局

#### 结局
根据失败原因触发不同结局：
- **燃料不足**：补给断绝，弹尽粮绝
- **耐久归零**：战舰沉没，同归于尽
- **胜利**：惨胜，推动维新思潮

## 道具系统

| 道具 | 效果 | 掉落概率 |
|------|------|---------|
| 燃料 | 恢复18点燃料 | 高 |
| 回血 | 恢复12点耐久 | 中 |
| 强化 | 双发弹药，持续10秒 | 5% |
| 护盾 | 抵挡一次伤害，一次性 | 5% |
| 射速提升 | 射速提升约1.7倍，持续15秒 | 5% |
| 信号干扰 | 所有敌人及弹幕减速，持续6秒 | 5% |

## 敌人类型

| 类型 | 血量 | 速度 | 伤害 | 特征 |
|------|------|------|------|------|
| 侦察艇 | 18 | 快 | 5 | 高速低血量 |
| 巡洋舰 | 45 | 中 | 10 | 中等均衡 |
| 战列舰 | 110 | 慢 | 22 | 高血量高伤害，燃料掉落率提升 |

敌舰血量随波次递增（每波+12%）。

## 游戏特性

### 资源管理
- **燃料**：持续消耗，移动时消耗加速，冲刺时消耗加倍
- **耐久**：受到攻击时减少，归零则游戏失败
- 拾取道具恢复资源并获得分数

### 无敌帧
- 受击后触发45帧（0.75秒）无敌状态
- 无敌期间玩家贴图闪烁虚化
- 敌方弹幕穿透玩家，不造成碰撞

### 导弹轰炸（第三战）
- 第三战开始后，战场会出现导弹轰炸区
- 轰炸区有预警提示，爆炸半径80像素
- 对玩家伤害25，对敌人伤害10

## 胜利/失败条件

- **生存模式胜利**：完成10波敌人进攻
- **故事模式胜利**：击败三场战斗的所有敌人
- **失败**：燃料耗尽 或 耐久度归零

## 得分系统

击杀敌舰和拾取道具均可获得分数：
- 击杀侦察艇/巡洋舰：10分
- 击杀战列舰：50分
- 拾取燃料：5分
- 拾取回血：8分
- 拾取强化：15分
